# Мини-приложение MAX-бота (кнопка «Открыть»)

Инструкция для администратора бота в MAX. В чате с ботом есть кнопка
«Открыть». Она запускает мини-приложение, то есть страницу, которую
отдаёт наш бот (`apps/max-bot`). На странице есть:

- приветствие по имени из профиля MAX;
- кнопка **«Записаться на консультацию»**. Мини-приложение закрывается, а в
  чате бот сразу начинает запись: согласие → имя → телефон → email → заявка
  в Bitrix24. Это тот же сценарий, что и после кнопки «Записаться» на старте;
- кнопка **«Задать вопрос в чате»**. Она просто возвращает в чат с ботом;
- блок **контактов**: телефон, email, сайт, ВКонтакте. Ссылки кликабельные.

Все тексты страницы редактируются в дашборде без программиста (см. шаг 3).

## 1. Какой адрес указывать

```
https://psi-opora-max.orixon.ru/
```

Это тот же сервер, на который MAX шлёт сообщения боту. Вебхук живёт по
адресу `https://psi-opora-max.orixon.ru/api/webhook`, а мини-приложение
открывается с корня, `/`. Если бота перенесут на другой домен, адрес будет
`https://<домен из MAX_WEBHOOK_URL без /api/webhook>/`.

Требования MAX к ссылке: только `https://`, только латиница, цифры, точки и
дефисы, без пробелов, не длиннее 1024 символов.

> Если по кнопке «Открыть» сейчас показывается ошибка, первым делом
> проверьте, что в настройках стоит именно этот адрес. Частые причины ошибки:
> старый адрес (например, `*.vercel.app` из шаблона `.env.example`) или путь
> `/api/webhook`. Откройте адрес в обычном браузере: должна появиться
> страница «Психологический центр «Опора»».

## 2. Как прописать адрес в MAX

1. Откройте платформу для партнёров MAX:
   [business.max.ru/self](https://business.max.ru/self). Войдите под
   аккаунтом, к которому привязан бот.
2. Перейдите в раздел **«Чат-боты»** и нажмите **«Перейти»**.
3. Найдите нашего бота (`id525603925717_bot`), нажмите **⋮** → **«Настройки»**.
4. В поле ссылки на мини-приложение вставьте адрес из шага 1.
5. Выберите тип кнопки: **«Открыть»** (рекомендуем), «Старт», «Играть» или
   кнопку без названия.
6. Нажмите **«Сохранить»**.

Кнопка появится в чате с ботом. Если её не видно, закройте и заново откройте
чат или перезапустите приложение MAX. Адрес, тип кнопки и отключение
мини-приложения меняются там же: **⋮ → «Настройки»**.

## 3. Как поменять тексты и контакты

Дашборд «Пси-Опора» → **Настройки → Бот** (`/settings/bot`) → раздел
**«Мини-приложение в MAX»**. Что там можно поменять:

| Поле                       | Что это                                                                 |
| -------------------------- | ----------------------------------------------------------------------- |
| Заголовок                  | Крупная строка вверху страницы                                          |
| Приветствие                | `{name}` заменяется на имя клиента; без имени выводится просто «Здравствуйте!» |
| Описание                   | Абзац под приветствием                                                  |
| Кнопка «Записаться»        | Надпись на главной кнопке                                               |
| Кнопка «Задать вопрос»     | Надпись на второй кнопке                                                |
| Контакты                   | По одной строке на пункт. Ссылки `https://…`, email и телефоны становятся кликабельными. Пустое поле скрывает блок |

Правки появляются на странице в течение минуты. Перевыкладывать бота не
нужно.

## 4. Ссылки с параметром (реклама, сайт)

**Открыть сразу мини-приложение** с меткой источника:

```
https://max.ru/id525603925717_bot?startapp=VK
```

Метка (`VK` в примере) может содержать латиницу, цифры, `_` и `-`. Если
клиент нажмёт в мини-приложении «Записаться», метка попадёт в сделку как
источник, так же, как при обычном диплинке в бота. Без метки ссылка такая:
`https://max.ru/id525603925717_bot?startapp`.

**Сразу в запись на консультацию**, минуя мини-приложение. Подходит для
кнопки на сайте:

```
https://max.ru/id525603925717_bot?start=CONSULT
https://max.ru/id525603925717_bot?start=CONSULT_VK
```

Здесь есть ограничение MAX. Параметр `?start=` доходит до бота только при
**первом** запуске (или после того, как клиент остановил бота). Клиент,
который уже переписывался с ботом, по такой ссылке просто попадёт в чат,
и запись сама не начнётся. Кнопка «Записаться» внутри мини-приложения этого
ограничения не имеет и работает всегда.

## Для разработчика

- Страница: `apps/max-bot/src/webapp/page.ts`. Маршруты `GET /` и
  `POST /webapp/consult`: `apps/max-bot/src/webapp/routes.ts`.
- «Записаться» шлёт на сервер `window.WebApp.initData`. Сервер проверяет
  подпись токеном бота (`init-data.ts`, алгоритм из
  [dev.max.ru/docs/webapps/validation](https://dev.max.ru/docs/webapps/validation)),
  затем прогоняет через бота синтетический `bot_started` с payload
  `CONSULT[_<start_param>]`. Дальше работает обычный `handleStart` →
  `matchesConsultStartParam` → `startConsultation`.
- Тексты лежат в `SCENARIO_TEXT_DEFS` (`packages/bot-core/src/scenario/texts.ts`),
  ключи `webapp_*`.
