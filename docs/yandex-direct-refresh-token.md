# Как получить Refresh Token для Яндекс.Директа

Эта инструкция рассчитана на человека без опыта программирования — просто
выполняйте шаги по порядку, ничего дополнительно понимать не нужно.

**Зачем это вообще нужно.** Чтобы сайт мог сам, без вашего участия,
запрашивать у Яндекс.Директа статистику по рекламе, Яндексу нужно один раз
разрешить это специальным «пропуском» — он называется **refresh token**
(«токен обновления»). После того как вы его получите и вставите в нужное
поле, всё остальное система будет делать сама.

Получать токен нужно под той учёткой Яндекса (тем логином), у которой есть
доступ к нужным рекламным кабинетам Директа — то есть под тем аккаунтом,
которым вы обычно заходите в Директ и видите там свою рекламу.

Куда потом вставить результат:
- в дашборде — раздел «Настройки → Реклама» (поле «Refresh Token»), **это
  самый простой вариант**, если у вас есть доступ к дашборду;
- либо в файл настроек сервера, в переменную `YANDEX_REFRESH_TOKEN` (это
  вариант для того, кто настраивает сервер напрямую, см.
  [.env.example](../.env.example)).

Шаги 1–5 одинаковые для любого компьютера. Разница только в шаге 6 — команда
для обмена кода на токен вводится по-разному в Windows и в macOS/Linux, ниже
даны готовые варианты на выбор.

## Шаг 1. Создайте приложение на сайте Яндекса

«Приложением» здесь называется просто запись в системе Яндекса, которая
даёт нашему сервису право спрашивать разрешение у вашего аккаунта. Создавать
и настраивать её нужно один раз.

1. Откройте в браузере страницу
   [oauth.yandex.ru/client/new](https://oauth.yandex.ru/client/new).
2. Если Яндекс попросит войти — войдите под той учёткой, у которой есть
   доступ к рекламным кабинетам Директа.
3. В поле «Название» впишите любое понятное название, например
   `psi-opora Direct`. На дальнейшие шаги оно не влияет.

Если такое приложение уже создавалось раньше, откройте его в
[списке ваших приложений](https://oauth.yandex.ru/) вместо создания нового.

## Шаг 2. Укажите платформу и адрес возврата

1. На той же странице найдите раздел **«Платформы»**.
2. Выберите **«Веб-сервисы»**.
3. В поле **«Redirect URI»** (адрес, куда Яндекс вернёт вас после
   подтверждения доступа) впишите ровно это значение, без изменений:

   ```
   https://oauth.yandex.ru/verification_code
   ```

   Это специальная служебная страница самого Яндекса — она нужна именно
   для такого «ручного» способа получения токена, без своего сайта-приёмника.

## Шаг 3. Разрешите доступ к Яндекс.Директу

1. Найдите раздел **«Доступ к данным»** (иногда называется «Scopes» или
   «Права доступа»).
2. В поиске по списку прав введите `Директ` и отметьте галочкой пункт,
   который даёт доступ к API Яндекс.Директа (техническое имя права —
   `direct:api`).
3. Больше никакие права отмечать не нужно.

## Шаг 4. Сохраните и скопируйте два секретных значения

1. Нажмите кнопку **«Создать приложение»** (или «Сохранить», если правили
   существующее).
2. Откроется страница приложения с двумя полями:
   - **ClientID** — идентификатор приложения (не секретный, но записать
     нужно точно);
   - **Client Secret** («Пароль») — это уже секретное значение, никому его
     не показывайте и не публикуйте.
3. Скопируйте оба значения в текстовый файл или сразу вставьте:
   - в дашборде — в поля «Client ID» и «Client Secret» на странице
     «Настройки → Реклама»;
   - или в переменные `YANDEX_CLIENT_ID` / `YANDEX_CLIENT_SECRET` в файле
     настроек сервера.

Они понадобятся ещё раз буквально через минуту, на следующих шагах —
не закрывайте эту страницу.

## Шаг 5. Получите одноразовый код подтверждения

1. Возьмите **ClientID**, скопированный на предыдущем шаге.
2. Подставьте его вместо `ВАШ_CLIENT_ID` в ссылку ниже и откройте
   получившуюся ссылку в браузере (в том же, где вы вошли под нужной
   учёткой Яндекса):

   ```
   https://oauth.yandex.ru/authorize?response_type=code&client_id=ВАШ_CLIENT_ID
   ```

   Например, если ClientID — `abc123def456`, ссылка должна выглядеть так:
   `https://oauth.yandex.ru/authorize?response_type=code&client_id=abc123def456`

3. Яндекс покажет страницу с запросом доступа — нажмите **«Разрешить»**.
4. После этого откроется страница с крупно написанным набором цифр и
   букв — это и есть **код подтверждения**. Скопируйте его целиком.

   Важно: этот код живёт всего несколько минут. Если не успели —
   ничего страшного, просто откройте ссылку из пункта 2 ещё раз и получите
   новый код.

## Шаг 6. Обменяйте код на токены

Теперь нужно один раз отправить Яндексу запрос, в котором вы «предъявляете»
код из прошлого шага вместе с ClientID и Client Secret, а Яндекс в ответ
присылает токены. Делается это не в браузере, а через программу для
выполнения таких запросов — она уже есть на любом компьютере, нужно только
знать, как её открыть.

Сначала подготовьте команду: возьмите один из вариантов ниже (в зависимости
от вашей системы) и замените в нём:
- `КОД` — на код из шага 5;
- `ВАШ_CLIENT_ID` — на ClientID из шага 4;
- `ВАШ_CLIENT_SECRET` — на Client Secret из шага 4.

### Если у вас Windows

1. Нажмите на клавиатуре сочетание **Win + R**, введите `powershell` и
   нажмите Enter — откроется синее (или чёрное) окно командной строки.
2. Вставьте в него команду ниже (сначала подставив своё, как описано выше)
   и нажмите Enter:

   ```powershell
   Invoke-RestMethod -Method Post -Uri "https://oauth.yandex.ru/token" -Body @{
       grant_type    = "authorization_code"
       code          = "КОД"
       client_id     = "ВАШ_CLIENT_ID"
       client_secret = "ВАШ_CLIENT_SECRET"
   }
   ```

3. Через пару секунд появится ответ в виде списка полей — нужно значение
   напротив `refresh_token`.

   Если оно длинное и обрывается на экране — выполните ту же команду ещё
   раз, добавив в конец ` | Format-List` (это покажет каждое поле на
   отдельной строке целиком):

   ```powershell
   Invoke-RestMethod -Method Post -Uri "https://oauth.yandex.ru/token" -Body @{
       grant_type    = "authorization_code"
       code          = "КОД"
       client_id     = "ВАШ_CLIENT_ID"
       client_secret = "ВАШ_CLIENT_SECRET"
   } | Format-List
   ```

### Если у вас macOS или Linux

1. Откройте программу «Терминал».
2. Вставьте команду ниже (подставив своё) и нажмите Enter:

   ```bash
   curl -X POST https://oauth.yandex.ru/token -d "grant_type=authorization_code&code=КОД&client_id=ВАШ_CLIENT_ID&client_secret=ВАШ_CLIENT_SECRET"
   ```

3. В ответ придёт текст в фигурных скобках — найдите в нём
   `"refresh_token":"..."`.

### Технические детали (можно пропустить)

Команда выше — это HTTP-запрос `POST https://oauth.yandex.ru/token`. В
Windows он показан через `Invoke-RestMethod`, а не через `curl`, потому что
в PowerShell имя `curl` — это встроенный алиас команды `Invoke-WebRequest` с
другим набором параметров, и привычный по интернет-инструкциям синтаксис
`curl -d "..."` там работать не будет. Если всё же нужен именно curl — в
Windows 10/11 есть настоящий `curl.exe`, и та же bash/macOS-команда, что
выше, сработает и в cmd.exe, и в PowerShell, если вызвать её явно как
`curl.exe -X POST ...`.

## Шаг 7. Сохраните refresh_token

Скопируйте значение `refresh_token` целиком (это длинная строка из букв и
цифр) и вставьте:
- в дашборде — в поле «Refresh Token» на странице «Настройки → Реклама»,
  затем нажмите «Сохранить»;
- или в переменную `YANDEX_REFRESH_TOKEN` в файле настроек сервера.

Значение `access_token` из того же ответа сохранять никуда не нужно —
сервис сам получает свежий access-токен по refresh-токену перед каждым
запросом к Директу, вручную обновлять ничего не придётся.

## Если через некоторое время реклама перестала обновляться

Refresh token у Яндекса не бессрочный. Если отчёты по рекламе перестали
обновляться и в логах/ошибке видно `invalid_grant` — значит, токен истёк.
В этом случае просто повторите шаги 5–7 (создавать приложение заново,
шаги 1–4, не нужно).
